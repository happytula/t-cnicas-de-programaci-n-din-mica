Etiquetas Semánticas: Section y Hgroup

HTML5 introdujo etiquetas semánticas que aportan significado estructural al código, facilitando la lectura tanto para los navegadores como para los desarrolladores.

La etiqueta <section>

Representa una sección genérica de contenido en un documento, la cual generalmente incluye un encabezado. Se usa para agrupar bloques de contenido relacionados temáticamente.

<section>
  <h2>Últimas Tecnologías</h2>
  <p>Contenido de la sección...</p>
</section>

La etiqueta <hgroup>

Se utiliza para agrupar un conjunto de elementos de encabezado (como <h1> a <h6>), combinando un título principal con subtítulos o descripciones alternativas.

<hgroup>
  <h1>Diseño Web Moderno</h1>
  <p>Guía práctica de maquetación y CSS</p>
</hgroup>
