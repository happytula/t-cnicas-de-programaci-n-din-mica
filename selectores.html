Selectores CSS

Los selectores son los patrones que se utilizan para seleccionar los elementos HTML a los que se les aplicarán las reglas de estilo. Constituyen la base fundamental para aplicar diseño de forma precisa.

Tipos de Selectores Principales:

1. Selector de Etiqueta: Selecciona todos los elementos que coincidan con el nombre de la etiqueta HTML.

p {
  color: #334155;
}

2. Selector de Clase (.): Permite aplicar estilos a cualquier elemento que tenga asignado dicho atributo de clase.

.btn-nav {
  background-color: #2563eb;
}

3. Selector de ID (#): Selecciona un único elemento específico basado en su identificador único (debe ser único en todo el documento).

#principal {
  font-weight: bold;
}
