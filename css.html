Hojas de Estilo y Declaraciones

Las hojas de estilo en cascada (CSS) permiten separar el contenido HTML del diseño visual. Una lista de declaraciones se compone de propiedades y valores aplicados a un selector.

selector {
  propiedad: valor;
  color: #2563eb;
}

Esto otorga flexibilidad total para estructurar páginas atractivas y adaptables a cualquier dispositivo.
